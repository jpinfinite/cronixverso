# 🌌 Cronixverso

Portal de tecnologia, inteligência artificial, hardware, ciência e jogos.

## 🚀 Sobre o Projeto

O **Cronixverso** é uma plataforma moderna voltada para entusiastas e profissionais de tecnologia, trazendo artigos aprofundados, análises de mercado, notícias em tempo real e curadoria das ferramentas mais inovadoras da indústria.

---

## 🛠️ Tecnologias Utilizadas

- **Frontend:** React + TypeScript + Vite
- **Estilização:** Tailwind CSS
- **Ícones:** Lucide React

---

## 💻 Como Rodar o Projeto

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/jpinfinite/cronixverso.git
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. **Acesse no navegador:**
   `http://localhost:5173`
